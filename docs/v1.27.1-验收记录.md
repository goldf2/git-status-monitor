## 修正范围

- 修正“依赖验收”摘要的统计语义：任务只要存在未通过的验收条件，或状态为“所有自动检查通过，待人工验收”，即计入“验收待处理”；同一任务只计一次。
- 将摘要文案由“验收未完成”改为“验收待处理”，避免把自动条件全部通过误解为人工验收已经完成。
- 保持 Local Project Manager 数据边界不变：修正只影响只读投影的派生统计，不写任务、验收、CSV 或 Git。
