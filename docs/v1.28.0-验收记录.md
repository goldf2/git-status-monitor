# GitFinder v1.28.0 验收记录

日期：2026-08-28

## 功能范围

- 新增 Finder 风格“复制为路径名”：工具栏“操作”、文件右键菜单、应用“编辑”菜单均提供入口。
- macOS 使用 `⌥⌘C`，Windows/Linux 使用 `Ctrl+Shift+C`；多选按当前目录顺序将绝对路径逐行写入系统文本剪贴板。
- 保持两套剪贴板语义分离：普通复制/剪切继续使用 GitFinder 会话内文件剪贴板；复制路径名只写系统文本剪贴板，不改变文件粘贴候选。
- 主进程对每个路径重新执行真实受管路径和文件类型校验，拒绝受管根外路径、缺失项、非普通文件/文件夹、符号链接逃逸、超量和超大文本请求。
