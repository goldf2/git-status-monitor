# GitFinder v1.27.0 验收记录

日期：2026-08-28

## 本次范围

- 新增“依赖验收”任务视图，独立于任务列表、看板、时间线和里程碑显示，并保存用户的视图偏好与滚动位置。
- 从 Local Project Manager schema 1.1 权威 `data.json` 投影 `dependencies`，为任务附加前置与后继关系；支持 FS、SS、FF、SF 语义和正负滞后天数。
- 按项目与关键词筛选存在依赖或验收事实的任务，汇总依赖连线、关联任务、验收未完成和阻塞数量。
- 在详情中并列展示前置门禁、后继影响和验收条件，可在关系任务之间跳转，也可进入完整任务详情或项目目录。
- 保持数据边界：依赖和验收视图为只读投影，不读取或改写 Local Project Manager 的原始 CSV，不自动执行 Git，不提供直接写回按钮。
- 将仓库详情编排迁入独立控制器并保持异步请求代次隔离，旧仓库请求不能覆盖新选择。
