# GitFinder 距离开发型 Finder 替代工具的差距

更新时间：2026-08-28

## 结论

GitFinder 已具备“目录 + Git + 文档 + 终端 + 项目/任务/里程碑投影”的工作台骨架。v1.2.0 至 v1.25.0 依次补齐可恢复文件整理、Quick Look、跨根搜索、安全 Git 审查、Local Project Manager 权威写回、任务/里程碑工作台、可取消并发状态、Finder 菜单化交互与 macOS 发布门禁。v1.26.0 进一步将项目身份与 Git 属性分离，交付便携项目清单、多仓库聚合、三种文件冲突策略、结构风险确认、Finder 式分栏/图库、海量目录渐进显示、列表/普通图标网格虚拟窗口与非持久化性能诊断、文件/文本感知的编辑菜单、安全文件重做和 Windows x64 代码/CI 交付链。v1.27.0 新增只读“依赖验收”工作台，把权威投影中的 FS/SS/FF/SF 前后置关系、滞后天数和验收门禁聚合到同一检查界面；v1.27.1 根据真实桌面验收将自动条件未完成与等待人工验收统一计入“验收待处理”，避免摘要误报为零。v1.28.0 增加受管路径复核后的“复制为路径名”，通过工具栏、右键、应用菜单和跨平台快捷键把单项或多项绝对路径写入系统文本剪贴板，同时保持文件复制剪贴板的会话边界。v1.30.3 已由真实 `windows-latest` runner 生成首个 Windows x64 NSIS/ZIP 未签名测试版，覆盖源码、运行时、安装与卸载；但启动脚本强制附加了 `--disable-gpu`，随后真实虚拟机双击闪退证明它没有覆盖默认启动。v1.30.4 改为 Windows 内建软件渲染、关闭 WebGL、记录 GPU/渲染进程异常，并已在真实 `windows-latest` runner 不带补救参数通过免安装和安装后默认启动、安装、运行时与卸载验证，修复测试版已发布；原虚拟机仍待用户复验。下一切片把关系白板部署节点的环境、版本、分支、提交和声明状态结构化，并让手工节点、Coolify 快照、搜索和部署摘要共用。当前版本仍不能完整替代 Finder/文件资源管理器；Windows 10/11 物理设备、高 DPI、UNC、文件占用与 SmartScreen 人工验收也仍未完成。

## 本轮已完成的基础改进

- 仓库 ID 改为稳定身份，目录移动自动重绑定。
- 分类统计只使用当前扫描结果，不再出现负数。
- 批量 Git 状态在主进程限制默认 6、最大 12 并发，提供可见进度、子进程取消和旧请求隔离，默认不 fetch。
- 后退、前进与上级目录固定分组，动态显示目标位置，并提供 ⌘[、⌘] 与 ⌘↑ 快捷键。
- 工具栏、应用“前往”菜单及 macOS `⌘⇧G` / Windows `Ctrl+L` 共用“前往文件夹”弹窗；主进程只解析已存在的受管目录，支持 `~` 和成对引号，拒绝相对路径、普通文件、受管根外位置与符号链接越界。
- 侧栏收藏夹统一为文件夹位置：普通、Git 与项目文件夹从操作菜单、右键菜单和详情共用同一受信切换入口；Git/项目视觉属性保留，重命名和移动沿既有路径事务重绑定，不再创建或切换名为“收藏”的仓库标签。
- 左侧“项目”作为可折叠快捷导航而非分类或一级视图：显示所有项目、固定项目与最近项目；具体项目进入统一目录页，“所有项目”应用全局项目筛选。偏好只保存稳定项目 ID、名称和最近时间，路径移动后重新解析，失效固定项明确可见并可取消。应用设置可隐藏项目区/最近项目、设置 3/5/8 个最近上限或只清除最近记录。
- 受管根只能通过系统文件夹选择器的一次性、短时、精确路径授权加入；渲染层配置写入采用偏好白名单，不能覆盖根目录或收藏。项目文档读写拒绝符号链接、硬链接和越界目标。
- 内嵌终端只接受真实受管工作目录，每条命令均由主进程显示包含完整 cwd 与命令的原生确认；取消是默认选项。确认后仍是系统 shell，不把该确认误述为沙箱。
- 隐藏项目可从排列菜单、应用设置或 ⌘⇧. 切换；主视图与左侧目录树同步显示并降低隐藏项透明度，后台仓库扫描与全文索引仍保持原有忽略边界。
- 顶部工作区只保留文件浏览、仪表盘和开发任务；项目与 Git 仓库迁入内容筛选，并分别提供当前目录条件和所有受管位置预设。文件新建/操作、内容筛选和排列选项均使用可访问弹出菜单，支持方向键、Home/End、Escape、点击外部关闭和禁用态同步。
- 正式 App Logo 同步提供 1024px PNG、macOS ICNS 和 Windows ICO，自定义打包脚本显式指向对应平台资产。
- 配置采用原子写入，损坏配置先备份再恢复。
- Git 参数不再拼接进 shell；Web 服务仅监听本机且写操作默认关闭。
- Electron 开启沙箱、CSP、导航/新窗口限制和 IPC 发送方校验。
- 启动后后台核对仓库索引，减少路径漂移长期残留。
- 建立 Node 回归测试和发布前检查入口。
- 目录模式显示普通文件，卡片和列表都提供大小、修改时间与默认应用打开。
- 支持 ⌘/Shift 多选、新建、单项/批量重命名、批量移动和系统废纸篓。
- 文件操作只限显式受管根目录，拒绝覆盖、自嵌套、根目录和系统保护路径。
- 移动/重命名同步仓库注册表、收藏和分类；操作历史持久化并支持 ⌘Z 撤销。

- 文件内容与匹配片段不进入持久化索引；结果片段受长度限制并在渲染时转义，旧查询取消状态不会覆盖新查询进度。
