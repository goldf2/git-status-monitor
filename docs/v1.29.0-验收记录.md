# GitFinder v1.29.0 验收记录

日期：2026-08-28

## 功能范围

- 新增本机文件标签：普通文件和文件夹可分配一个或多个自定义名称与颜色的标签；标签与项目颜色、生命周期、仓库标签及 Git 状态保持独立语义。
- 工具栏“操作”和 Finder 风格右键菜单均提供“分配标签…”；应用设置新增统一的标签定义管理入口，可创建、改名、改色和删除标签。
- 图标、列表、分栏、图库四种目录视图统一显示标签；可在当前目录的高级内容筛选中按一个或多个文件标签筛选，多个选中标签采用 OR 语义。
- 标签定义和路径分配只保存在本机 GitFinder 配置中，不写入 `.gitfinder/project.json`、项目文件或 Git；全局范围搜索不会携带当前目录的路径标签条件。
- 文件移动、重命名、移到废纸篓及恢复时，标签路径会随现有配置事务同步迁移、归档或恢复；删除标签会同时清除孤立分配。
- 主进程重新验证标签操作目标必须位于受管目录内，且为真实普通文件或目录；拒绝受管根外路径、符号链接逃逸、缺失项和超量请求。

## 未完成边界

- 文件标签当前是本机路径元数据，不随项目配置跨设备同步；移动到 GitFinder 受管操作之外的路径时，应用无法自动感知并迁移标签。
- 当前提供按标签筛选和多视图显示，尚未提供 Finder 式标签侧栏、批量颜色面板、标签搜索建议或跨目录标签聚合视图。
- Windows 代码路径已有自动化覆盖，但本版本未生成 Windows 产物，也未在真实 `windows-latest` 或 Windows 10/11 设备上验收。
- 本机包为开发测试包；未进行 Developer ID 签名、公证或正式发布。
