# GitFinder v1.20.0 验收记录

日期：2026-08-27

## 本版结果

- 移动、重命名、废纸篓和撤销中的路径重绑定，将仓库注册表、扫描仓库清单和用户配置纳入同一个预写日志事务。
- 配置文件使用 `0600` 权限的唯一临时文件、文件同步和原子替换；中途写入失败会恢复全部磁盘文件与内存快照。
- 启动时会将未完成的预写事务一致地向前恢复，或完成已标记的回滚；损坏、超限或不是普通文件的记录原样保留并拒绝新的路径事务。
- 传输在“全部目标已提交、操作历史尚未落盘”窗口异常退出后，启动恢复会补齐移动的路径关联和可撤销历史。
- 批量传输只完成部分项目、来源与目标同时存在、或隐藏临时项可能是唯一副本时，不猜测删除或回滚，而是原样保留并请求人工检查。
- 启动恢复结果通过受信 IPC 显示给用户；完成的恢复与需要人工检查使用不同提示级别。
