## 持久化索引边界

- 索引保存在 GitFinder 用户数据目录的 `workspace-content-index.json`，使用临时文件写入后原子替换，文件权限为 `0600`。
- 索引只包含根目录编号、相对路径、类型、大小、修改时间、扩展名、Git 仓库标记和目录快照；没有文件内容字段。
- 根目录配置或 schema 不匹配、JSON 损坏、路径越界时不会采用旧缓存，而是重新构建完整索引。
- 已完成的索引才会发布；取消或失败的扫描不会用半成品覆盖上一份完整缓存。

## 当前限制

- 索引上限仍为 100,000 项；超大根目录会显示截断提示，结果不是根目录全部内容。
- 增量判断使用目录修改时间。新增、删除和重命名会使所在目录重新读取；只修改文件正文不会触发目录重读，但当前搜索本身不索引正文。
- GitFinder 内部文件操作会主动使索引失效；其他应用造成的变化需要点击“更新索引”吸收。
- 正式对外发行仍需要 Developer ID、Apple 公证和真实用户设备发布门禁。
