# GitFinder v1.19.0 验收记录

日期：2026-08-27

## 本版结果

- 全局搜索可直接使用 GitFinder 仓库分类和标签名称定位仓库，并继续支持文件、文件夹和仓库类型筛选。
- 文件系统索引仍只保存名称、路径、类型、大小、修改时间和 Git 仓库标记；分类与标签在每次查询时从 GitFinder 本机配置即时叠加，不重复写入持久化索引。
- 修改分类或标签后无需让目录索引失效或重新扫描；普通文件及普通文件夹不会继承所在仓库的元数据。
- 仓库结果在路径下方最多显示三个分类/标签胶囊，更多项目使用数量提示折叠；名称、颜色和返回数量均受清理与上限约束。
- 本功能不读取、复制或改写 Local Project Manager 的任务事实；Local Project Manager 仍只通过既有权威投影与受确认写回流程接入。
