# GitFinder v1.22.0 验收记录

日期：2026-08-27

## 本版结果

- 项目模式的 Git 状态统一进入主进程批次；默认并发 6，最大 12，单次最多 1,000 个去重绝对路径。
- 批量 IPC 逐项校验真实路径位于已添加的受管开发目录；默认 `autoFetch: false`，状态刷新不隐式联网。
- 每轮读取有独立请求 ID、实时完成/运行/等待数和取消入口。取消会停止排队仓库并向正在运行的 `git` 子进程传入 abort signal。
- 新刷新会先取消旧批次；渲染层拒绝任何非当前请求的进度、Git 结果和本地元数据，避免旧结果覆盖新界面。
- 状态栏连续显示“正在读取 Git 状态 n/total”、取消中、已取消或完成反馈；窄状态栏保持单行，并遵守减少动效设置。
- 正式 App Logo 使用深石墨底座、蓝灰文件夹、紫色 Git 分支和青色定位箭头；保留 1,254px 母版，并输出 1,024px RGBA PNG、macOS ICNS 和 256px Windows ICO。
- macOS 和 Windows 自定义打包脚本显式使用对应图标；母版作为源资产保留在仓库，不写入发布包。
