# GitFinder v1.26.0 验收记录

日期：2026-08-27

## 本次范围

- 将目录语义、项目身份与 Git 属性分离。
- 左侧目录树与主内容区统一为四态图标：普通文件夹、文件夹 + Git 角标、彩色项目文件夹、彩色项目文件夹 + Git 角标；Git 不再改变文件夹基础颜色。
- 新增便携 `.gitfinder/project.json`、设为项目/项目设置、可配置颜色、生命周期与多仓库聚合。
- 新增应用设置页；顶部齿轮、macOS `⌘,` / Windows `Ctrl+,` 与应用菜单均可进入，集中配置目录视图、排序、主题、终端、编辑器和 Git 环境。
- 新增可持久化语义色配置：普通目录与默认项目使用蓝色体系，Git 角标使用独立紫色；四个角色色位、十种生命周期标签色均可自定义并提供访达语义、高对比和柔和预设。卡片顶端横条继续表示 Git 综合状态，设置页新增已同步、未提交、未推送和需拉取图例，不与仓库身份色混用。
- 顶部一级工作区收敛为文件浏览、仪表盘和开发任务，不再把项目身份与 Git 属性当成独立页面。漏斗式内容筛选显式分为“当前目录”和“所有受管位置”：基础类型单选，项目与 Git 属性可组合；所有位置提供项目和 Git 仓库预设。范围、条件、面包屑、状态栏和标签提示由统一 `contentQuery` 驱动并按标签页持久化；旧项目/仓库模式和目录类型只作为一次性迁移输入。仓库分类不再占用左侧固定区块，而是迁入全部仓库与仪表盘的筛选下拉；全部仓库分类随标签页保存，仪表盘分类保持隔离。左侧继续保留访达式仓库标签。
- “更多筛选…”使用独立可访问弹窗提供仓库 Git 状态、项目生命周期、扩展名、最近 24 小时/7/30/90 天、包含边界的精确起止日期、三档文件大小与精确最小/最大大小。精确大小接受 B/KB/MB/GB/TB 并持久化为完整字节；反向日期/大小范围和非法输入保持弹窗打开且不修改当前查询。Git 综合状态多选为 OR、无远程为独立 AND，并与全部仓库筛选栏共享标签页查询；仪表盘临时筛选保持隔离。生命周期多选自动限定项目，扩展名/大小自动限定文件且与项目条件互斥；精确日期贯通当前目录、所有项目与所有仓库。工具栏显示高级条件数量。所有位置不递归扫描所有文件，普通筛选不会读取文件内容或为当前目录自动读取 Git 状态。
- 新增本机智能集合：所有项目／所有 Git 仓库的当前统一查询、名称/README 搜索字段和仓库标签可命名保存，点击侧栏条目确定性恢复。没有集合时侧栏区块隐藏；旧侧栏顺序自动把新区块放到“位置”之后。集合支持直接拖动重排，并从“更多”按钮或右键菜单重命名、上移、下移和仅移除快捷入口。当前目录筛选明确禁用保存，避免固化易失效绝对路径；集合最多 50 个，损坏、重复 ID 和超限记录安全清理，名称和顺序写入失败不会发布半完成状态。该功能不复制文件、不修改 Git、`.gitfinder/project.json` 或 Local Project Manager 数据。
- 新增 Finder 式逐目录显示偏好；可继续使用全局默认，也可让每个目录分别记住图标/列表/分栏/图库、排列依据、方向和分栏宽度。记录限制为最近 500 个，损坏项安全丢弃，Windows 路径按大小写不敏感规范化，目录移动时随配置事务重绑定。
- 分栏宽度支持 180–520 像素安全范围、鼠标拖动、方向键 16 像素微调、Shift 加速、Home/End 边界跳转和双击恢复 260 像素；设置页提供全局滑杆，开启逐目录记忆后由目录记录覆盖。可访问分离器同步公开范围和当前像素值。
- 新增 Finder 式分栏与图库视图；分栏从最深受管根生成最多 6 个祖先列并自动聚焦末端。图库以安全大预览配合横向胶片条显示栅格图片、Markdown、开发文本、目录摘要和不支持格式提示，复用单选、多选、范围选择、拖拽、右键、Quick Look 和文件操作。可见图片由主进程按需生成 192×128 PNG 缩略图，最多 4 个并发，主进程与渲染层缓存各限制为最近 128 项；来源受 12 MB 上限、受管真实路径和符号链接边界约束。文本 DOM 限制为 8,000 字符，Markdown 外链不可点击，异步预览与缩略图均带目录/请求竞态校验。macOS `⌘1/2/3/4`、Windows `Ctrl+1/2/3/4` 切换四种视图。
- 四种目录视图新增可取消渐进显示；超过 320 项时同步生成前 120 项，后续每帧最多补齐 180 项，内容区和状态栏显示进度且不截断目录数据。全选与 Shift 范围选择继续使用完整目录顺序，尚未生成的条目出现时继承选择状态；切换目录、视图或标签页会取消旧批次，迟到目录读取不能覆盖新位置。
- 超过 1,000 项的列表视图新增固定行虚拟窗口：DOM 只保留视口附近可见行和前后各 10 行过扫描，滚动时按动画帧换窗；完整目录数据与排序仍保留在状态模型中，`⌘A`/`Ctrl+A`、Shift 范围选择、Home/End、上下键和新建文件定位继续使用全量顺序。每个渲染行公开 `aria-posinset`/`aria-setsize`，切换目录或视图时销毁滚动和窗口监听。
- 超过 1,000 项且条目均为普通文件/文件夹的图标视图新增响应式多列虚拟窗口：按 280 像素最小卡片宽度和 12 像素间距动态计算列数，以固定 120 像素卡片高度和 132 像素行距只生成可见行及前后两行过扫描；窗口宽度变化时保持原顶部项目。带项目身份、Git 属性、标签、分组、README 或提交摘要的富卡片保持既有可变高度与渐进显示，不为虚拟化压平语义。方向键按当前列数跨行，Home/End、Shift 范围和全选继续基于完整目录顺序。
- “排列与显示”菜单新增当前目录本次性能诊断：记录目录读取、筛选准备、首批 DOM、完整显示、来源/可见项目数、当前 DOM 数和实际显示策略。新目录或视图请求取消旧样本；指标只存在当前渲染进程内存，不写本机配置、项目、Git 或索引，不读取额外文件内容，并明确标注为当前设备的瞬时测量。
- 新增隐藏项目浏览开关；排列菜单、应用设置及 macOS `⌘⇧.` / Windows `Ctrl+Shift+.` 均可切换，偏好保存在本机。直接浏览可进入 `node_modules`，仓库扫描与全文索引仍继续忽略依赖目录和隐藏内容。
- Quick Look 新增开发文件结构化预览：YAML、TOML 与 XML plist 显示结构导航和带行号源码，日志按时间、级别与消息分列并区分严重程度。二进制 plist 默认只提示格式；macOS 仅在用户明确点击“转换后预览”后，由受信主进程无 shell 调用 `/usr/bin/plutil`，把 stdout 作为内存只读 XML 交给同一 plist 结构视图。入口限制为受管真实 `.plist`、`bplist00`、8 MB 来源/输出、10 秒执行，并在转换后复核路径和文件版本；Windows/Linux 不显示转换入口。
- Quick Look 新增大型开发文本按需分页：首段最多 1 MB、后续每段最多 256 KB、累计最多 8 MB，界面只保留当前分段并延续源码行号。分页能力令牌随机生成、五分钟过期、单次消费并绑定真实受管路径与文件版本；关闭界面、文件变化、越界、重复请求或后续二进制内容都会撤销或拒绝继续读取。
