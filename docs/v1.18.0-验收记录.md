# GitFinder v1.18.0 验收记录

日期：2026-08-26

## 本版结果

- 复制、移动、剪切粘贴、内部拖放和外部导入统一进入零写入传输预览。
- 预览递归统计顶层项目、文件、目录、符号链接和总字节，识别同卷原子移动或跨卷复制后删除，并读取目标卷可用空间、预留 64 MiB 安全余量。
- 非原子传输先写入目标目录内的隐藏临时项；每个普通文件复制后执行 SHA-256 字节比对，整项结构和来源修订再次核对后才提交最终目标。
- 准备阶段可取消，取消会清理隐藏临时项且保持来源不变；进入短暂提交阶段后锁定取消，跨卷移动只在所有目标提交后删除来源。
- 活动传输以 `0600` 原子记录到用户数据目录；重启恢复只清理记录中通过受管路径校验的隐藏临时项。来源和最终目标同时存在等歧义状态不会自动删文件，而是保留原样并提示人工检查。
- 操作历史或路径关联写入失败时同时回滚文件和路径关联；不完整回滚会保留恢复记录并进入 `needs-review`。

## 当前边界

- 点击确认后的重新预检是只读过程，传输状态创建前暂不接受取消；实际分块复制与字节校验阶段可取消。
- 删除到系统废纸篓和撤销仍沿用既有移动路径；遇到跨卷时尚未显示同级容量、进度和取消界面。
- 恢复流程不猜测用户意图：来源和最终目标同时存在时不会自动删除任一份。
- 当前构建仍为 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。
