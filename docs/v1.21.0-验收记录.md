# GitFinder v1.21.0 验收记录

日期：2026-08-27

## 本版结果

- 全局搜索新增“名称与路径／文件内容”显式模式切换；默认仍为元数据搜索，内容模式按工作区标签页保留。
- 内容搜索复用现有增量索引的文件候选，仅为当前查询读取受管根内的白名单文本；文件内容和匹配片段都不进入持久化索引。
- 查询至少 3 个字符，单文件最多 512 KB，单次最多 2,500 个文件和 64 MB；扫描进度显示文件数和已读取字节，达到上限会明确提示。
- 文本解码支持 UTF-8 和带 BOM 的 UTF-16LE/BE；二进制、非白名单、超限文件、符号链接和搜索前被替换到受管根外的项目会跳过。
- 切换查询、离开全局搜索或点击取消会停止内容读取；请求进度相互隔离，旧查询的取消结果不覆盖新查询。
- 结果显示匹配行号和最长 240 字符片段；外部文本使用文本转义后再渲染，窄窗口下模式和类型控件保持单行并可水平滚动。
