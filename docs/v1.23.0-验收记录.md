# GitFinder v1.23.0 验收记录

日期：2026-08-27

## 本次范围

- 把后退、前进、上级目录组成固定的 Finder 式导航组，禁用时仍保留清晰轮廓。
- 后退、前进和上级目录动态提示实际目标位置，增加 `⌘[`、`⌘]`、`⌘↑` 快捷键。
- 将目录/仓库/仪表盘/开发任务从四段平铺切换为“工作区视图”菜单。
- 将新建文件/文件夹收进“新建”菜单，将复制、粘贴、重命名、移动、废纸篓和撤销收进“操作”菜单。
- 将目录类型筛选以及排序字段、方向、卡片/列表布局收进两个紧凑菜单。
- 菜单支持方向键、Home/End、Escape、Tab、点击外部和窗口失焦关闭；选中态、禁用态和触发器文案随当前状态同步。
- 修复“刷新”按钮被通用排序监听器误捕获、可能把排序字段写成空值的问题。

- 当前 macOS 仅为 ad-hoc 签名，未完成 Developer ID 正式签名和 Apple 公证。

- `127.0.0.1:3001` 是旧版辅助 Web 监控页，不代表 Electron 桌面界面；本轮桌面验收以打包 App 为准。
