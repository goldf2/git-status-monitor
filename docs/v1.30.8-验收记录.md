# GitFinder v1.30.8 验收记录

日期：2026-08-28

## 功能范围

- 目录页“操作”、文件/文件夹右键菜单和系统“文件”菜单增加“在终端中打开”。
- 没有选择时打开当前真实目录；单选文件夹时打开该文件夹；单选文件时打开文件所在目录。
- 多选、全局搜索未选择项目、非目录浏览上下文和受管范围外目标不猜测工作目录。
- 终端目标选择迁入独立渲染控制器，主进程继续复用应用设置中的首选终端；工具不可用时引导用户进入开发工具设置。
- 修复菜单中按 Return 被全局目录快捷键截获、错误触发“重命名”的问题；菜单内的 Return、空格和方向键由菜单自身处理。

## 安全边界

- 渲染层只传递候选文件或目录路径；主进程通过文件服务重新解析真实受管路径，并只接受普通文件或真实目录。
- 文件目标转换为父目录，目录目标保持自身；符号链接、缺失目标和受管目录之外的路径均拒绝。
- 此入口只启动已配置的外部终端并传入工作目录，不执行 shell 命令，不自动 stage、commit、push，也不扩大受管根。
- 内嵌终端的逐命令原生确认机制保持不变，与本次外部终端入口是两个不同能力。
